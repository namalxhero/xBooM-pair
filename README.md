# xBooM Pair (Vercel)

Website that makes a pairing code and a SESSION_ID for the xBooM bot.

Deploy: import this repo on vercel.com (Framework preset: Other).
Optional env var `PAIR_KEY` = access key required to use the site.
Uses the bundled `xBooM-BAILEYS` library (fork of Baileys by WhiskeySockets, MIT - see its LICENSE).
